## Reproduced defects

- Failed best-score requests returned an empty success result and replaced
  offline scores. Errors now reach the existing cache fallback.
- Legitimate zero-percent scores were omitted. They now remain visible.
- Sectional uploads used only the first section for difficulty, while edits
  used the full passage. Both now use canonical combined content.
- The processing worker preserved a user's fiction choice without sending
  it to the processor. The optional classification now reaches the prompt
  and output validation, preserving summary requirements and bounded retries.
- Model output could replace an existing user title. User titles now win.
- Empty or failed reader selections did not retry after difficulty changed.
  Pending requests could also overwrite a retained passage after reversing
  a filter. Request ownership now follows the selected genre and latest range.
- Old PvP search responses could replace newer results or a selection reset.
  Search completion, errors, and loading now belong to the latest request.
- Valid recovery links failed after Supabase consumed their URL hash.
  Password reset now waits for the existing authenticated session provider.
- Abandoned login, signup, and password-reset requests could schedule a
  redirect after unmount. Lifecycle guards stop those continuations and
  preserve valid StrictMode behavior and scheduled-timer cleanup.
- Long quizzes placed their questions and actions outside small viewports.
  The shared dialog now scrolls within the viewport. Arrow keys inside
  dialogs no longer move the hidden reader.
- Retired text channels could change state or deliver old-account events.
  Channel identity guards reject them. Text, notification, and PvP channels
  also cancel pending replacement timers when the same channel recovers.

Each defect has a failing-before-fix regression. Changes retain the existing
architecture, components, dependencies, validation, and worker authorization.
Independent final review and Thermo-Nuclear review checked the substantive
diff. Comment review found no actionable comment changes.

tables have RLS, and PvP games retain FULL replica identity. Catalog review
checked policies, grants, function owners, search paths, triggers, processing
revision behavior, and the legacy hosted admin endpoint.

All five stored sectional difficulties were compared with the actual shared
calculation. One mismatch was corrected from 13 to 12 through hosted SQL,
with an optimistic revision guard and a rollback rehearsal. The metadata-only
repair enqueued no inference. Three old private, short non-fiction records
without summaries were retained rather than replacing legacy user content.

Recent health checks showed nine active cron jobs, 150 successful runs,
zero failed runs, 60 successful worker responses, no transport failures, and
empty processing queues. No schema migration, dump, or SQL fixture is stored
in this repository. Sanitized hosted verification remains outside it.
