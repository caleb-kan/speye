## Material limits

- No physical webcam/calibration accuracy, live paid inference, full OAuth/email delivery, two-account live PvP WebSocket session, assistive-technology session, or production load test was performed.
- The production domain returned Cloudflare's HTTP403 challenge to the audit browser. The Cloudflare PR preview was accessible with the real Supabase public library: a 288-word read completed at 288/288 with no horizontal overflow or console errors. Authenticated and private flows remain covered by local tests rather than a live two-account session.
- Supabase leaked-password protection remains disabled. The Management API returned HTTP402 because the feature requires Pro or above; no subscription upgrade was performed. See [Supabase password security](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection).
- Guarded SECURITY DEFINER RPCs remain deliberately callable for application workflows. The public leaderboard RPC is deliberately anonymous. Advisor warnings about these grants are not resolved by breaking their authorized callers. Thirteen unused-index notices were retained without evidence that removing those indexes improves the actual workload.
- Quiz validation intentionally samples the first set and bounded source/summary excerpts to stay within the provider budget. Maintenance handlers explicitly skip sources outside their supported contracts.
- Three existing nonsectional texts exceed the 8,000-character processing budget. They remain readable; regenerating them requires shortening or sectioning their source rather than silently moderating a prefix.
- Legacy queued records without historical activity identities cannot be retroactively deduplicated reliably. Legacy quiz replay is bounded by its original completion timestamp.
- Browsers without Web Locks use the existing replay fallback without cross-tab serialization. Stable activity IDs prevent duplicate activity insertion, but that fallback does not provide one origin-wide critical section for every operation type.
- Hard document unload can prevent pending requests from settling. Keepalive cancellation and the existing stale-queue cleanup remain the recovery path. Private channel membership does not turn self-reported progress or quiz/WPM input into a tamper-proof measurement.
